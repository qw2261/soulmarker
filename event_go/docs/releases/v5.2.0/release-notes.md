# v5.2.0 Release Notes

> 状态：Verification

## 目标

建立 G0 基线，并完成第一批 G1 正确性与隐私修复。

## 计划变化

- 统一生产与集成测试 Router。
- 修复 PostDetail 契约。
- 校验门票、帖子与活动的嵌套资源归属。
- 增加更新参数校验。
- 报名名单进入管理员认证边界。
- 增加当前用户报名状态接口。
- 建立 CI、Docker ignore 和测试追溯文档。
- 收紧 JSON 请求边界并增加安全响应头、稳定错误码和内部错误脱敏。
- 引入 schema 版本 3 的事务化迁移框架，完成用户 ID 字段的 Expand 阶段。

最终发布内容以实际验证 Commit 为准。
