# v5.5.0 Migration and Rollback

## 数据兼容性

本阶段不修改数据库 Schema 或持久化数据；新增 `/api/v1`，不需要数据迁移和备份恢复操作。

API v1 与旧 `/api` 使用同一 Handler；前端切换到 v1 后仍可通过回滚前端制品继续访问兼容路由。

错误响应继续保留原数字 `code`、中文 `message` 和 HTTP 状态；新增的专用 `error_code` 替代早期按 HTTP 状态生成的通用值。客户端应按新目录判断业务原因，并在未知字符串时使用 HTTP 状态和通用错误展示。

## 回滚

1. 停止候选应用。
2. 部署上一候选制品。
3. 复验健康检查、登录、报名、取消、发帖和管理写接口。

回滚不需要手工改库。内部构造函数签名发生变化，尚未对外提供 Go SDK，因此不存在外部兼容承诺。

回滚会使 `error_code` 退回通用值，依赖专用业务码的新版客户端必须与后端候选同步回滚。
