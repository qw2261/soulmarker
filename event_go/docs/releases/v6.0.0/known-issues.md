# v6.0.0 Known Issues

> 缺陷等级、Owner 与最晚关闭阶段统一维护在 [缺陷台账](../../testing/defect-register.md)。JWT 与 Go 标准库 P1 修复等待远端候选门禁。

- 当前运营核销使用全局 Admin Token；租户角色、核销员身份和完整 actor 审计归 G5。
- 当前页面支持扫码枪或粘贴凭证，尚未集成移动浏览器摄像头扫码。
- 历史 phone-only 账户在能够登录且知道当前密码时可自助绑定恢复邮箱；已经失去登录能力且尚未绑定邮箱的账户仍需要受控人工身份核验流程。
- 历史 contact 若规范化后发生邮箱大小写碰撞，迁移会让相关账户全部保持未绑定，禁止自动选择其中一个账户取得恢复权限。
- 密码重置已具备 SMTP 适配器和生产 fail-closed 配置，但尚未在真实 staging SMTP 完成投递、退信和链接跳转验收。
- 当前密码重置限流按已知用户每分钟一次执行，尚未接入 G6 的边缘/IP 限流与异步通知重试；邮件发送失败会记录服务日志，客户端仍返回统一 202。
- G4 业务通知仅提供持久化站内信，不发送业务邮件或短信，也没有浏览器 Push；导航未读数在页面加载和已读操作时刷新，不保证实时到达。
- 临近提醒调度器适用于当前单实例 SQLite 部署；多实例部署前必须升级为带租约的单执行者或外部任务系统。服务停机跨过整个提醒窗口时不会补发已经过时的“活动开始前”提醒。
- 内容治理当前只覆盖文本帖子和回复；没有申诉流、批量处置、自动风险识别、媒体附件审核或举报频率限制，这些能力需在真实运营数据和角色模型明确后迭代。
- 若数据库已有 removed 内容，直接回滚到 pre-v9 应用会重新暴露这些内容；必须使用保留治理过滤的兼容回滚制品或维护模式前滚。
- 活动封面当前使用运营方提供的外部 HTTP/HTTPS 图片地址，尚未提供上传、裁剪、自有对象存储/CDN 和失效图片巡检。
- G4 自动化浏览器矩阵为桌面 Chromium 与 Pixel 7 Chromium；公开生产前仍需补 macOS Safari/iPhone WebKit 和目标 Android Chrome 真机或等价云设备验证。
